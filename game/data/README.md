# Data resources

`.tres` files that hold parameters and references to exported assets. Scripts in `game/src/` declare exported properties of Resource types; scenes assign these files to them. Editing a file here, in the Inspector or in a text editor, changes behavior without changing code.

A Resource file shared by several scenes changes all of them when edited. To vary one scene, duplicate the file and assign the copy.
